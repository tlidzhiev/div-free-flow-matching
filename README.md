## About

Conditional flow matching for 2D incompressible velocity fields. The model generates
velocity fields of a forced 2D Kolmogorov flow on a periodic domain, conditioned on the
Reynolds number, and the generated fields should stay divergence-free.

## Installation

### Requirements
- Python 3.13.18
- TPU/CUDA (optional, for TPU/GPU support)

### Setup

```bash
# Clone the repository
git clone https://github.com/tlidzhiev/div-free-flow-matching.git
cd div-free-flow-matching

# Install uv (if not already installed)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create virtual environment
uv venv --python 3.13.18
source .venv/bin/activate

# Install dependencies via uv
uv sync --all-groups

# Install pre-commit
pre-commit install
```

### CometML Configuration

CometML is used by default for experiment tracking. Create a `.comet.config` file in the project root:

```ini
[comet]
api_key=YOUR_API_KEY
workspace=YOUR_WORKSPACE
project_name=YOUR_PROJECT_NAME
```

The API key is only needed for online logging: `writer.mode` is `offline` by default.

## Data

The dataset is generated by a pseudo-spectral solver (`lab.dataset.solver`) of the
vorticity equation

```
d_t w + u . grad w = nu lap w - alpha w - k_f cos(k_f y),   domain [0, 2pi)^2
```

with drag `alpha = 0.1` and forcing wavenumber `k_f = 4`. Each trajectory starts from a
random band-limited vorticity, is spun up onto the attractor, and snapshots are taken every
`--t-snap` time units. Velocity is recomputed from the truncated vorticity, so the stored
fields are divergence-free on the output grid.

```bash
uv run scripts/generate_data.py --out data/kolmogorov
```

With the default arguments this produces 64x64 fields for Re in [100, 1000]:

| split | samples | Reynolds numbers |
|-------|--------:|------------------|
| train | 8192    | log-uniform (one per trajectory) |
| val   | 1024    | 100, 200, 500, 1000 |
| test  | 2048    | 100, 200, 500, 1000 |

Splits are made by trajectory. The condition is `c = 2 (log nu - log nu_min) / (log nu_max - log nu_min) - 1`,
i.e. `c = +1` at Re = 100 and `c = -1` at Re = 1000. Files of a split (`fields.npy`,
`c.npy`, `re.npy`, ...) and the full description of the layout are documented in
`scripts/generate_data.py` and `data/kolmogorov/meta.json`.

For a fast smoke test of the pipeline:

```bash
uv run scripts/generate_data.py --out data/kolmogorov_debug --sim-n 128 \
  --train-traj 4 --val-traj-per-re 1 --test-traj-per-re 1 --n-snapshots 4 --spinup 5
```

## How To Use

To run a script (training or inference), use the following command:

```bash
uv run <script> -cn=CONFIG_NAME HYDRA_CONFIG_ARGUMENTS
```

- `<script>`: Use `train` for training or `inference` for inference
- `CONFIG_NAME`: A config file from `src/lab/configs` (`train` and `inference` by default)
- `HYDRA_CONFIG_ARGUMENTS`: Optional Hydra overrides

The dataset path `data/kolmogorov` is relative to the repository root.
Runs are saved to `logs/{project_name}/{run_name}`, with checkpoints in the `checkpoints`
subdirectory.
